# SARA — Interactive Landing Page

A visually immersive landing page featuring a real-time **powder-flow water background** rendered on HTML5 Canvas, built with **Vite + TypeScript**.

---

| File | Role |
|---|---|
| `index.html` | Defines the page: canvas element, hero section with "SARA" title, search bar, announcement button, and a BMI calculator form with inline client-side JS |
| `water.ts` | The star feature — 1,200 particles flowing through a noise field with mouse-scatter interaction. Exported as `initWaterBackground()` |

| `script.php` + `utils/helpers.php` | Server-side PHP fallback for BMI calculation (the page also calculates BMI client-side in `index.html`) |

## How to Run

### Prerequisites

- **Node.js** v18+ and **npm** (or **Bun** as an alternative)

### Step 1 — Install dependencies

```bash
npm install
```

> If npm blocks postinstall scripts (for `esbuild` and `@biomejs/biome`), approve them:
> ```bash
> npm approve-scripts esbuild
> npm approve-scripts @biomejs/biome
> ```

### Step 2 — Start the dev server

```bash
npm run dev
```

This runs `vite --host 0.0.0.0`. Open your browser to:

```
http://localhost:5173
```

### Step 3 — Build for production

```bash
npm run build
```

Outputs static files to `dist/`. Preview the production build:

```bash
npm run preview
```

### NPM Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start Vite dev server with hot reload (port 5173) |
| `npm run build` | Type-check (`tsc`) + production build to `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm run lint` | Run Biome linter |

## How It Was Made

### The Powder-Flow Water Background (`water.ts`)

This is the centerpiece visual effect. Here's how it works:

#### 1. Trail Buffer (motion trails)

Instead of clearing the canvas every frame, a semi-transparent overlay is painted:

```ts
ctx.fillStyle = 'rgba(4, 6, 12, 0.055)';
ctx.fillRect(0, 0, W, H);
```

This means each frame only partially erases the previous one. Particle trails fade slowly — creating the silky, lingering look of powder drifting in air.

#### 2. Noise-Based Flow Field

A 256×256 grid of random angles is sampled with **smoothstep interpolation** to produce a smooth, continuous direction field. Particles read the flow angle at their position and are gently pushed along it:

```
particle.vx += cos(angle) * 0.15
particle.vy += sin(angle) * 0.15
```

The field slowly evolves over time (`time += 0.005`), so the current direction shifts organically — never repeating identically.

#### 3. 1,200 Soft Particles

Each particle stores its previous position (`px`, `py`) and draws a **short line** from previous to current position. This creates natural flowing streaks rather than hard dots. Particles use **HSL colors** across a palette of deep blues, teals, and violets, with occasional warm sparks.

#### 4. Additive Blending

```ts
ctx.globalCompositeOperation = 'lighter';
```

Particles add their color to whatever is beneath. Where many particles overlap, brightness accumulates — giving a luminous, glowing quality.

#### 5. Mouse Interaction (Powder Scatter)

When the mouse moves, particles within a 180px radius are:

- **Pushed away** from the cursor (radial repulsion)
- **Given the mouse's velocity** (directional scatter)

This mimics throwing a handful of powder — particles fly in the direction of your hand, then settle back into the ambient flow via damping (`velocity *= 0.96`).

#### 6. Click Burst

Clicking spawns 60 particles radiating outward from the click point at random angles and speeds — like a fistful of powder thrown into the air.

#### 7. Lifecycle Management

Each particle has a `maxLife` (300–900 frames). It fades in at birth and fades out at death using `sin(lifeRatio * π)` — ensuring no pop-in or pop-out. Dead particles are replaced to maintain ~1,200 alive at all times.

### Frontend Interactivity (`main.ts`)

- **Search bar** — Focus glow, typing detection, simulated search with loading spinner
- **Button particles** — Every button click spawns 8 radial particles
- **Click ripples** — Click anywhere creates an expanding radial gradient
- **Keyboard shortcuts** — Space = color burst (20 particles), Enter = focus search, Escape = blur search
- **Hamburger menu** — Mobile navigation toggle

### Styling (`style.css`)

- **Glassmorphism** — `backdrop-filter: blur()` on search bar and buttons
- **Gradient text** — The "SARA" title uses `background-clip: text` with an animated glow
- **Responsive** — Breakpoints at 768px and 480px
- **Canvas** — Fixed full-screen behind all content (`z-index: -1`)

### PHP BMI Calculator (`script.php` + `utils/helpers.php`)

Server-side BMI calculation is available via PHP. The page also has an inline client-side JavaScript BMI calculator in `index.html` that works without a server. The PHP version is a fallback for server-rendered results.

## Tips

- **Move your mouse** across the screen to scatter particles like powder
- **Click** anywhere for a burst
- **Press Space** for a full-screen color burst
- **Press Enter** to focus the search bar
- **Press Escape** to unfocus
